# Анализ A/B-теста нового алгоритма ранжирования новостей 📰

*Учебный проект в рамках программы профессиональной переподготовки «Аналитик данных» (НИУ ВШЭ), 2025–2026.*

## 📌 О проекте

Данный проект выполнен в рамках домашнего задания по курсу «Прикладная статистика» программы переподготовки НИУ ВШЭ. Задача — провести полный цикл анализа A/B-теста нового алгоритма ранжирования новостей: от разведочного анализа данных (EDA) до проверки статистических гипотез, визуализации результатов и оценки влияния ботов на итоговые выводы.

## 📌 Цель проекта

Отработать полный пайплайн анализа A/B-теста:
- **EDA** — исследование структуры данных, динамики метрик и поиск аномалий;
- **проверка гипотез** — оценка статистической значимости отличий между группами с помощью подходящих тестов;
- **визуализация** — оценка «видимости» и стабильности эффекта во времени;
- **контроль качества данных** — оценка влияния ботов на результаты эксперимента.

## 🎯 Задание 1 — Разведочный анализ данных (EDA)

### 📁 Данные

- **Источник:** учебный датасет `news.csv` (статистика АБ-теста алгоритма ранжирования в новостях)
- **Размер:** 251 693 строки, 38 столбцов
- **Гранулярность:** одна строка = пользователь + день
- **Период:** 25 апреля — 2 мая 2023 (8 дней)
- **Группы:** `control` (125 455 строк) и `хронология` (тест, 126 238 строк)
- **Уникальных пользователей:** 237 971

**Ключевые метрики:**
- `total_clicks_` — клики по поисковой выдаче за день;
- `time_to_first_click_` — суммарное время до первого клика;
- `first_click_pos_`, `sum_pos`, `end2end_sum_pos` — позиции кликов;
- `queries` — количество запросов;
- `empty_results` — количество запросов с пустой выдачей.

### 📊 Что сделано

1. **Загрузка данных и парсинг даты** (`d` → `dt`).
2. **Ответ на вопрос 1:** сколько пользователей совершило клик 1 мая 2023 года — **33 409**.
3. **Динамика количества кликов по дням** за всё время (общая и по группам).
4. **Анализ влияния бинарных флагов** (`is_vtb`, `is_yandex`, `is_sber`, `is_yandex_bot`, `bot_flg`) на метрику кликов:
   - Mann-Whitney U test, корреляция Спирмена, точечно-биссериальная корреляция.
5. **Корреляция `queries` ↔ `total_clicks_`** (Пирсон, Спирмен, heatmap).

### 📈 Ключевые результаты

**Зависимость кликов от флагов:**

| Флаг | Доля кликов при =1 | Корреляция | Вывод |
|------|-------------------|------------|-------|
| `is_vtb` | 0.0% | — | кликов нет (мало данных) |
| `is_yandex` | 0.0% | −0.319 (pointbiserial) | абсолютный индикатор не-клика |
| `is_sber` | 0.0% | — | кликов нет (мало данных) |
| `is_yandex_bot` | 0.0% | −0.535 (Спирмен) | абсолютный индикатор не-клика |
| `bot_flg` | 0.9% | −0.913 (pointbiserial) | **сильный** детектор ботов |

**Вывод:** метрика кликов статистически значимо зависит от флагов `is_yandex`, `is_yandex_bot` и `bot_flg`. При установке в 1 кликов либо нет вообще (`is_yandex`, `is_yandex_bot`), либо почти нет (`bot_flg`). Для `is_vtb` и `is_sber` данных недостаточно.

**Корреляция `queries` ↔ `total_clicks_`:**
- Пирсон: **r = 0.628** (умеренная положительная)
- При этом p-value = 0.096 — **статистически незначимо** (мало наблюдений: всего 8 дней).

## 🎯 Задание 2 — Проверка гипотезы

### 📊 Метрики и подходы

| № | Метрика | Метод |
|---|---------|-------|
| 1 | Среднее количество кликов на пользователя за весь период | Mann-Whitney U (данные ненормальные) |
| 2 | Средняя позиция клика (`sum_pos / клики`) | Mann-Whitney U |
| 3 | Средняя сквозная позиция клика (`end2end_sum_pos / клики`) | **Метод линеаризации** + t-test |
| 4 | Доля пустых результатов выдачи (`empty_results / queries`) | **Метод линеаризации** + t-test, z-test для пропорций |

### 📈 Результаты тестов (до фильтрации ботов)

| Метрика | Control | Test | p-value | Значимо? |
|---------|---------|------|---------|----------|
| 1. Клики на пользователя | 0.1427 | 0.1471 | 0.730 | ❌ |
| 2. Средняя позиция клика | 6.11 | 5.72 | 0.112 | ❌ |
| 3. Сквозная позиция (линеаризация) | 5.76 | −5.70 | 0.143 | ❌ |
| 4. Доля пустых результатов (линеаризация) | — | — | **0.000** | ✅ |

**Для справки по метрике 4 (z-test для пропорций):**
- Control доля: **53.71%**
- Test доля: **22.14%**
- z-statistic = 285.2, p-value ≈ 0

**Вывод:** статистически значимое отличие обнаружено **только для доли пустых результатов** — в тестовой группе она существенно ниже (22% против 54%). Остальные метрики значимых отличий не показали.

## 🧠 Отработанные концепции

- **EDA:** разведочный анализ, динамика метрик, анализ бинарных флагов, поиск аномалий.
- **Статистические тесты:** Mann-Whitney U (ненормальные данные), t-test, z-test для пропорций, корреляционный анализ (Пирсон, Спирмен, pointbiserial).
- **Метод линеаризации:** преобразование ratio-метрик для применения t-test (ключевой приём для метрик 3 и 4).
- **Визуализация:** скользящее среднее, накопленные линеаризованные метрики, bar chart разницы с цветовой индикацией.
- **Контроль качества:** оценка влияния ботов на статистические выводы, проверка устойчивости результатов.
- **Интерпретация:** различение «статистически значимого» и «практически значимого» эффекта, оценка effect size.
